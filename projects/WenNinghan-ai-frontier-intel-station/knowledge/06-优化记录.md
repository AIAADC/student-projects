# v1 → v2 优化记录

> 作业要求「基于真实使用体验做至少一轮优化」，此文件即优化过程的留痕。

## 时间线

- **v1（8/28 晚）**：搭建「AI 前沿情报站」Markdown 知识库（README / 每日简报 / 新模型追踪 / 横评实测 / 厂商动态），配置每日 9:00 自动简报任务，首期简报生成成功。
- **v1.5（8/29 早 9:00）**：自动化任务第二次运行成功，第 002 期简报自动生成 —— 连续两天零人工验证稳定，同时自动同步了新模型追踪表。
- **v2（8/29 中午）**：部署上线网页主页。

## 真实使用中发现的问题（v1 痛点）

1. **手机打不开**：内容全是本地 Markdown，躺在文件夹里，通勤路上想看昨夜 AI 动态做不到
2. **给别人看成本高**：想分享给同学，要发一堆 .md 文件，对方还得有 Markdown 阅读器
3. **入口太深**：最有价值的「今日头条」藏在 `01-每日简报/日期.md` 两层目录下，打开工作台不能一眼看到

## v2 改进项

| 痛点 | 改进 |
|------|------|
| 手机打不开 | 部署上线网页主页，微信/浏览器直接点开，移动端自适应 |
| 分享成本高 | 一个链接搞定：头条、时间线、存档全部可视化 |
| 入口太深 | 主页首屏即「今日头条」，时间线表格化呈现 |

## v3 改进项（8/29 晚 · 网页版大改版）

> 痛点来源：v2 上线后真实点阅发现——存档是死链、表格写死无法检索、实测区空缺、夜间看刺眼、手机端表格挤压。

| 痛点 | v3 改进 |
|------|---------|
| 简报存档是死链 `#` | 内置全文阅读器：点归档卡片 / 首页按钮，两期简报全文沉浸式阅读（Esc / 点遮罩关闭），手机端全屏适配 |
| 表格写死、内容多了没法用 | 追踪表数据驱动重构：关键词搜索、12 个厂商筛选 chip、点表头按日期/厂商排序、实时计数 |
| 实测区空缺 | 新增「模型擂台」：GLM-5.3-Flash vs Qwen3.8-Flash-Next 规格对比条形图（数据来自追踪表）+ 实测排期看板（3 条待测来自简报待办，诚实标注「排期中」，不造假数据） |
| 厂商动态排版单调 | 8 张厂商卡片 + 活跃/间接/观望三档状态灯 + 「未证实」爆料黄色角标高亮 |
| 夜间阅读刺眼 | 深色科技主题为默认 + 一键切换浅色，偏好本地记忆 |
| 自动化「不可见」 | 新增自动化引擎区块：5 步流水线可视化 + 「距第 003 期自动生成」实时倒计时（页面自己证明自动化活着） |
| 快速跳转可能看到空白 | 修复进场动画触发条件（threshold 0.12 → 0 + 大 rootMargin + 无 IO 兜底），修复 hero 统计数字不滚动问题 |
| 移动端表格挤压 | 全站移动端重排：导航折叠、双列统计、表格横向滚动、阅读器全屏 |

## v3.1 改进项（8/29 晚 · 厂商看板二次迭代）

| 痛点 | v3.1 改进 |
|------|-----------|
| 头像是字母占位块 | 全部替换为官方品牌标识（内嵌 SVG 矢量、零外部依赖）：OpenAI / Anthropic / Gemini·Google DeepMind / Qwen·阿里通义 / KIMI·月之暗面 / DeepSeek / ByteDance·字节，智谱用官方 Z 字方标矢量重现 |
| 只能看最新动态，往期没入口 | 卡片保留最新简讯 + 底部新增「查看历史动态 N 条」；点击卡片弹出该厂商「动态档案」时间线（由近及远、日期锚点、随每日简报自动累积） |
| 历史数据来源 | 全部来自 001/002 两期简报与追踪表的已收录记录（共 30 条），未编造任何条目 |

## v3.2 改进项（8/29 晚 · 模型擂台可选对比）

> 痛点来源：v3 的擂台写死为「GLM-5.3-Flash vs Qwen3.8-Flash-Next」两款，想看 Hy4、Grok Code Fast 1 等新模型的对比做不到。

|------|-----------|

## v3.3 改进项（8/29 晚 · 规格补全 + 智能雷达）

> 痛点来源：对比池多数模型规格信息不全；缺少权威基准的性能对比维度。

| 痛点 | v3.3 改进 |
|------|-----------|
| 模型规格信息不全 | 联网核实并补全 18 款模型规格：Kimi K3（2.8T 参数 / ¥20+¥100 定价）、DeepSeek V4 Pro（1.6T-A49B / 全栈开源）、Claude Opus 4.8（$5/$25 / 1M）、GPT-5.6 Sol（$5/$30 / 1.05M）、Grok 4.6（500K / $2/$6）等；对比池扩充至 18 款并按厂商 optgroup 分组（一级厂商、二级模型），补入老旗舰方便「新 vs 老」对比 |
| 缺少权威性能对比 | 新增「智能雷达」：五维基准对比（综合智能 = AA/AI 指数 · 终端编程 = Terminal-Bench 2.1 · Agent 协作 = Hy4 官方盲测 · 长上下文 = 对数归一 · 视频生成 = Arena），随选择器联动出双多边形雷达图 |

## v3.4 改进项（8/29 晚 · 「工作台工具箱」：从资讯站到操作台）

> 痛点来源：培训负责人反馈「知识库是纯搜索+呈现，交互不足」——方向性意见：要的不是"看"，是"干活"。

| 痛点 | v3.4 改进 |
|------|-----------|
| 只能看，不能算 | 新增 **Token 成本计算器**：8 款有官方定价的模型双栏并排比价（含美元折算），改数字即时重算，自动输出"便宜 X%、省 ¥Y"；无官方定价的模型不参与，不编数字 |
| 实测只能去文件里记 | 新增 **实测记录器**：页内表单选两款模型、四维度（准确/速度/价格/体感）滑杆打分 → 自动生成对比卡（逐维赢家+总分+胜负），支持一键导出 Markdown 存回 03-横评实测笔记 |
| 待办只是文字 | 新增 **任务板**：简报「明日待办」同步为可勾选任务（默认 4 条来自简报），支持添加/删除，进度条可视化 |
| 模型没法追踪 | 新增 **⭐ 关注系统**：追踪表每个模型可收藏，集中到「我的关注」栏管理 |
| 刷新即丢 | 以上全部状态（任务/实测/关注）localStorage 持久化，刷新不丢 |

修复：工具箱初始化时事件绑定引用了错误的元素 id（#cA → #calcA），导致后续模块中断的 bug。

| 痛点 | v3.5 改进 |

| 移动端 | 顶栏 + 底部 Tab + 「更多」抽屉已由外壳提供，与侧栏样式统一 |

## v3.5.1 修复（8/29 晚 · 宽屏排版两处）

| 问题 | 修复 |
|------|------|
| 概览四张快捷卡横铺满屏（越宽越扁长） | 根因：`.qlinks` 在 `.wrap` 容器外，失去宽度约束。补 max-width + 居中，与上方内容像素级对齐 |
| 终端卡片每行日志被拆成多行（"+8 条"孤行） | 根因：类名冲突——终端高亮 `<span class="hl">` 撞上"今日头条"条目的 `.hl{display:flex}`，被块级化。终端高亮改用专用类 `.thl`；同时主内容区 1040→1140、终端列加宽（1.15fr:1fr），长日志单行放下；窄屏时 nowrap+横向滚动兜底（终端的惯常行为） |

## v3.5.2 改进（8/29 晚 · 布局留白 + 实测记录器诚实化）

| 问题 | 修复 |
|------|------|
| 工具箱左列卡片下方大片留白 | 根因：grid 默认 stretch 把两卡拉成等高。改 `align-items:start`，各卡恢复自然高度（实测 523px vs 812px） |
| 实测记录器看起来像"已对 18 款模型跑过分"的评测系统 | 诚实化改造：① 改名「实测打分卡」+「主观打分 · 非跑分」徽章 + 副标声明"没测过的模型，这里永远是空的" ② 新增**必填「测试任务」**——不写怎么测的就不能生成打分卡，机制上杜绝云评测 ③ 新增可选「实测凭据」（对话/截图链接） ④ 空态文案与导出 Markdown 同步带上任务与凭据字段 |
| 简报归档卡片标签与"阅读全文"角标重叠 | 根因：角标绝对定位无预留空间。卡片增加底部留白 48px |
