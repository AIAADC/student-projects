# UI 设计规范 v0:克制的高端风格(#30)

> 状态:**已取代** | 现行口径见 [ui-design-v1.md](./ui-design-v1.md)
> 原适用范围:apps/web 全部界面 | 对应 issue:#30;面板骨架增量 #107
> 本文保留作历史。新页面与组件必须服从 v1（v0 的灰阶 / 禁用清单 / 无深色模式仍成立，已并入 v1）。
> 这是给自己人天天用的工具面板,不是宣传页。高端感来自克制与秩序:留白、层级清晰、字重与灰阶的节制使用、动效只用于表达状态变化。

## 1. 原则

1. **克制**:一屏一个视觉重点;不用装饰性元素。
2. **秩序**:栅格与间距节奏统一,同类信息同层级。
3. **灰度优先**:颜色只表达语义(状态),不表达品牌或装饰。
4. **动效克制**:动效是状态变化的反馈,不是表演。
5. **文字即界面**:能靠字重与灰阶分出的层级,不用色块。

## 2. 颜色与灰阶层级

主色板就是灰阶(参考 Apple 中性色),语义色只保留三个:状态色。**除状态色外不引入其他彩色**(品牌色、主题色一律不加)。

| 用途 | Tailwind | 参考值 | 说明 |
| --- | --- | --- | --- |
| 页面背景 | bg-white | #ffffff | 浅色模式基底 |
| 主文本 | text-gray-950 | #030712 | 标题与正文首选 |
| 次级文本 | text-gray-600 | #4b5563 | 描述、元信息 |
| 弱化文本 | text-gray-400 | #9ca3af | 占位符、时间戳、哈希 |
| 边框 | border-gray-200 | #e5e7eb | 卡片、输入框 |
| 悬停边框 | border-gray-400 | #9ca3af | 可聚焦控件 |
| 底纹 | bg-gray-50 | #f9fafb | 标签、区块底、hover |
| 成功 | text-green-700 / bg-green-50 | | 仅"已启用"等状态 |
| 警告 | text-amber-800 / bg-amber-50 | | 仅离线提示等 |
| 错误 | text-red-700 / bg-red-50 | | 仅失败信息 |

规则:文本层级最多用三档(950/600/400);背景层级最多两档(white/gray-50);状态色只用浅底深字,不用深底白字,不用高饱和纯色。

## 3. 字号与字重档位

| 档 | Tailwind | 字号 | 字重 | 用途 |
| --- | --- | --- | --- | --- |
| 页面标题 | text-2xl font-semibold tracking-tight | 24px | 600 | 每页唯一 |
| 区块标题 | text-base font-medium | 16px | 500 | 卡片组标题 |
| 条目标题 | text-sm font-medium | 14px | 500 | 列表项主名 |
| 正文 | text-sm | 14px | 400 | 描述、说明 |
| 次要 | text-xs | 12px | 400 | 标签、哈希、时间 |
| 代码 | font-mono text-xs | 12px | 400 | 命令、哈希、路径 |

规则:标题不用 700+ 字重;不用斜体表强调;行高统一 1.5(标题可 1.25)。

## 4. 间距节奏

间距只用 4px 网格:

| 层级 | 值 | 用途 |
| --- | --- | --- |
| 页面边距 | px-6 / py-10 | 主容器 |
| 区块间距 | mb-8 / space-y-6 | 页内区块 |
| 卡片间距 | space-y-3 | 列表项 |
| 卡片内边距 | p-4 | 内容与边框 |
| 行内间距 | gap-2 / gap-3 | 控件组 |
| 元素内距 | px-3 py-2 | 输入框 |

## 5. 圆角与边框

- 卡片:rounded-xl(12px),1px border-gray-200,**无阴影**
- 输入框/下拉:rounded-lg(8px),1px border-gray-300(交互用 gray-400),focus 无光环,只变边框色
- 标签/胶囊:rounded-full,px-2 py-0.5,bg-gray-50 text-gray-600
- 按钮:主按钮 bg-gray-950 text-white;次按钮 border border-gray-300 bg-white

## 6. 动效

- 只允许 transition(颜色/边框/透明度),时长 100–150ms,上限 **200ms**;easing 默认
- 只挂在 hover/focus/状态切换上;禁止入场动画、弹跳、缩放、位移入场
- 数据加载用静态文案(如「加载中…」),不用 spinner 动画以外的任何旋转/骨架屏闪烁
- 状态变化(如启用/停用)可用 opacity + 位移不超过 2px 的过渡,或干脆无动效

## 7. 禁用清单(不要做什么)

- 渐变(背景渐变、文字渐变)一律禁止
- 玻璃拟态(backdrop-blur 叠层)一律禁止
- 彩色阴影/大阴影(box-shadow 彩色或超出 0 0 0 1px 的阴影)禁止
- 跳动/循环入场动画、滚动视差、粒子效果禁止
- 装饰性插画、emoji 当图标、icon 库的花哨变体禁止(需要图标时用极简线性,或纯文字)
- 荧光色/高饱和强调色禁止;唯一例外是 §2 的三个状态色
- 深底白字的按钮若与灰阶冲突(如灰底灰字)禁止,主按钮必须黑底白字
- 圆角超过 16px 的元素禁止(除胶囊标签)

## 8. 用 Tailwind CSS 4 表达

Tailwind 4 是 CSS-first:在 index.css 的 @import 后用 @theme 定义语义 token,组件里只引用 token 类:

    @import "tailwindcss";

    @theme {
      --color-ink-strong: #030712;   /* gray-950 */
      --color-ink-mid: #4b5563;      /* gray-600 */
      --color-ink-faint: #9ca3af;    /* gray-400 */
      --color-line: #e5e7eb;         /* gray-200 */
      --color-surface: #f9fafb;      /* gray-50 */
    }

组件规则:
- 文本:用 ink-strong / ink-mid / ink-faint,禁止直接 text-black 或自定义 hex
- 边框:border-line;底纹:bg-surface
- 状态色:直接 Tailwind 语义类(green-700 等),禁止自定义
- 引用本规范数值时写 Tailwind 类名(如 text-sm),不写 px 值

## 9. 深色模式结论

**v0 不做深色模式。** 理由:这是高频内部工具,浅色方案已足够;深色需要整套灰阶 token 反转与状态色对比度审计,半吊子深色比没有更伤。
后续在满足以下条件时再立 issue 做:1) 有明确用户需求;2) 浅色方案已稳定(至少一个完整面板落地);3) 由本规范 §8 的 token 体系承载(只需换 @theme 值,不污染组件)。

## 10. 虚拟列表行高(旧三栏遗留)

整页骨架已改为人用壳,见 §12 与 [app-shell-v2.md](../designs/app-shell-v2.md)。本节只保留仍在用的行高与批量条视觉,不再约束页面分栏。

### 10.1 三栏列宽与分隔

| 列 | Tailwind | 说明 |
| --- | --- | --- |
| 作用域 | `w-56 shrink-0` | 固定列宽 |
| 集合 | `min-w-0 flex-1` | 吃剩余宽度 |
| 检查器 | `w-[28rem] shrink-0` | 固定列宽 |

规则:列间只用 `border-r` / `border-l` 的 `border-line`,**不要 `gap-*`**。各列内部沿用 §4 的 `p-4`。主工作区容器为 `flex min-h-0 flex-1`,三列贴齐。

### 10.2 窄屏退化(`<lg`)

不做移动端专门设计。`<lg` 时:

| 列 | 规则 |
| --- | --- |
| 作用域 | `hidden lg:block`;改由顶栏 `<select>` 切换 |
| 集合 | 占满剩余宽度 |
| 检查器 | 未选中 skill 时 `hidden lg:block`;选中后 `fixed inset-0` 覆盖,`lg:` 回到静态列 |

### 10.3 集合列固定行高

虚拟滚动要求行高恒定。档位必须写在本规范,不能散落在组件里当魔法数字。

| 档 | Tailwind | 用途 |
| --- | --- | --- |
| 集合行 | `h-10` | 技能列表每一行(复选 + 名称 + 聚合或客户端开关) |

规则:行高只用这一档,不要另起 `h-11` / `h-12`。实现里若需要像素常量,值必须等于 `h-10`,不得私自改。选中用 `bg-surface`;焦点用内收的 `outline-line-strong`。不用阴影表达选中。

### 10.4 浮动批量条的层级

§7 已禁阴影与毛玻璃。批量条的层级用实体面 + 边框表达,不另开例外。

| 项 | Tailwind | 说明 |
| --- | --- | --- |
| 底 | `bg-white` | 实体条,不透明 |
| 上沿 | `border-t border-line` | 与内容区分界 |
| 宽 | 与主工作区同宽 | 不要做成悬浮卡片 |
| 内边距 | `px-4 py-2` | 略紧于 §4 的 `p-4`,因为是工具条 |

规则:禁止 `shadow-*`、`backdrop-blur`、半透明底。选中数为 0 时不渲染。

## 11. 例外裁定

与「克制」相冲突且本规范未覆盖的场景,默认按最保守方案;需要突破时先在 PR 里说明理由,由 review 裁定后回写本规范。

## 12. 人用壳(侧栏 + 隐藏滚动条)

人用 IA 见 [app-shell-v2.md](../designs/app-shell-v2.md)。§10 三栏只约束仍在用虚拟列表的行高,不再约束整页骨架。

### 12.1 侧栏

| 项 | Tailwind | 说明 |
| --- | --- | --- |
| 侧栏 | `w-56 shrink-0` | 固定宽 |
| 主区 | `min-w-0 flex-1` | 吃剩余宽度 |
| 分隔 | `border-r border-line` | 不要 `gap-*` |
| 设置 | 侧栏底部 | 左下角,与三个板块分开 |

### 12.2 滚动条

滚动保留,滚动条隐藏。在 `index.css` 全局写:

- `scrollbar-width: none`（Firefox）
- `::-webkit-scrollbar { display: none }`（Chromium / Safari）

不要用装饰性滚动条。页面根仍 `overflow: hidden`,分区 `overflow-y-auto`。
