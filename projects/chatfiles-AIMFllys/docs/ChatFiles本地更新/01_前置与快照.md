## 2. 快照基线（关键，MUST 在重跑解析 / digest 之前做）

目的：把"当前已分析到的水位"固化进 `data/insights/_state.json`，并备份当前 manifest 供比对。

### 2.1 备份当前 manifest

```powershell

```

### 2.2 首次更新：从现有 manifest 引导出 `_state.json`

仅当 `data/insights/_state.json` **不存在**时执行（后续更新已有 state，跳过本步、**不要**覆盖它）。把现有 manifest 里、且**已经有 `conv/*.json`** 的会话，记为"已分析到当前 textCount"。

参考脚本（可存为 `scripts/bootstrapInsightState.ts` 运行；纯本地、只读 wechat.db）：

```ts
// scripts/bootstrapInsightState.ts —— 仅首次更新跑一次
import fs from 'node:fs'
import path from 'node:path'
import { DatabaseSync } from 'node:sqlite'

const root = process.cwd()
const insDir = path.join(root, 'data', 'insights')
const statePath = path.join(insDir, '_state.json')
if (fs.existsSync(statePath)) { console.log('_state.json 已存在，跳过引导'); process.exit(0) }

// 与 prepChatDigests.ts §1.5 完全一致的 safe()
const safe = (id: string) => id.replace(/[<>:"/\\|?*@ -]/g, '_').slice(0, 90)

const manifest = JSON.parse(fs.readFileSync(path.join(insDir, '_manifest.json'), 'utf8')) as
  Array<{ convId: string; textCount: number }>

const db = new DatabaseSync(path.join(root, 'data', 'wechat.db'), { readOnly: true })
const lastTimeStmt = db.prepare('SELECT last_time FROM conversations WHERE id=?')

const state = manifest
  .filter((m) => fs.existsSync(path.join(insDir, 'conv', `${safe(m.convId)}.json`))) // 只认已分析过的
  .map((m) => {
    const row = lastTimeStmt.get(m.convId) as { last_time?: number } | undefined
    return {
      convId: m.convId,
      analyzedTextCount: m.textCount,
      analyzedLastTime: Number(row?.last_time ?? 0),
      analyzedAt: '(bootstrap)',
    }
  })

db.close()
fs.writeFileSync(statePath, JSON.stringify(state, null, 2), 'utf8')
console.log(`引导 _state.json：${state.length} 个已分析会话`) 
```

```powershell
npx tsx scripts/bootstrapInsightState.ts
```

> 说明：`analyzedAt:'(bootstrap)'` 和确定性的时间戳是刻意的——本仓库脚本环境里 `new Date()` 可用，但为可复现，引导阶段不强求真实时刻。后续真正分析时再写真实 `analyzedAt`。
