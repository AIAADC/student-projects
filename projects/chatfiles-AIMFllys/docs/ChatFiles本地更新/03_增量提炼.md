## 1. 算 delta + 生成"尾部 digest"

把下面存为 `scripts/computeUpdateDelta.ts` 并运行。它读取 `_manifest.json`（新）与 `_state.json`（基线），输出待提炼清单 `work/insights-delta/_delta.json`，并为每个待提炼会话写一份 digest 到 `work/chat-digest-delta/`（新增会话=全量；长大会话=仅 `time > 已分析时间` 的尾部）。

```ts
// scripts/computeUpdateDelta.ts
import fs from 'node:fs'
import path from 'node:path'
import { DatabaseSync } from 'node:sqlite'

const root = process.cwd()
const insDir = path.join(root, 'data', 'insights')
const deltaDigestDir = path.join(root, 'work', 'chat-digest-delta')
fs.mkdirSync(deltaDigestDir, { recursive: true })

const MIN_TEXT = 20        // 与 prepChatDigests.ts 一致：实质会话门槛
const DELTA_MIN_TEXT = 8   // 至少新增这么多条文本才值得重跑一个 agent（可调）
const CAP_CHARS = 48000    // 单份 digest 上限，与 prepChatDigests.ts 一致

// 与 prepChatDigests.ts §1.5 完全一致的 safe()，全管线 MUST 一致
const safe = (id: string) => id.replace(/[<>:"/\\|?*@ -]/g, '_').slice(0, 90)

const manifest = JSON.parse(fs.readFileSync(path.join(insDir, '_manifest.json'), 'utf8')) as
  Array<{ convId: string; name: string; isGroup: boolean; textCount: number }>
const stateArr = fs.existsSync(path.join(insDir, '_state.json'))
  ? JSON.parse(fs.readFileSync(path.join(insDir, '_state.json'), 'utf8')) as
      Array<{ convId: string; analyzedTextCount: number; analyzedLastTime: number }>
  : []
const state = new Map(stateArr.map((s) => [s.convId, s]))

const db = new DatabaseSync(path.join(root, 'data', 'wechat.db'), { readOnly: true })
const msgStmt = db.prepare(
  `SELECT time, sender_name, text FROM messages
   WHERE conv_id=? AND type=1 AND length(text)>0 AND time>? ORDER BY time`,
)
const fmt = (r: any) => {
  const dt = new Date(r.time * 1000).toISOString().slice(0, 16).replace('T', ' ')
  const who = (r.sender_name || '某人').slice(0, 18)
  return `[${dt}] ${who}: ${String(r.text).replace(/\s+/g, ' ').trim()}`
}

const delta: any[] = []
for (const m of manifest) {
  if (m.textCount < MIN_TEXT) continue
  const prev = state.get(m.convId)
  let kind: 'new' | 'grown'
  let since: number
  if (!prev) { kind = 'new'; since = 0 }
  else if (m.textCount - (prev.analyzedTextCount ?? 0) >= DELTA_MIN_TEXT) { kind = 'grown'; since = prev.analyzedLastTime ?? 0 }
  else continue // 没有实质新增 → 跳过，绝不重复分析

  const rows = msgStmt.all(m.convId, since) as Array<{ time: number; sender_name: string; text: string }>
  if (rows.length === 0) continue
  let body = rows.map(fmt).join('\n')
  if (body.length > CAP_CHARS) body = body.slice(0, CAP_CHARS) // 超大群可改用 prepChatDigests 的信息量抽样
  const header = `会话：${m.name}${m.isGroup ? '（群聊）' : '（私聊）'}\n` +
    `${kind === 'new' ? '全量（首次提炼）' : '增量（仅本次新增的尾部消息）'} · 约 ${rows.length} 条新文本\n\n`
  const digestPath = path.join(deltaDigestDir, `${safe(m.convId)}.txt`)
  fs.writeFileSync(digestPath, header + body, 'utf8')
  delta.push({ convId: m.convId, name: m.name, isGroup: !!m.isGroup, kind, digest: digestPath, newTextCount: m.textCount })
}

db.close()
const outPath = path.join(root, 'work', 'insights-delta', '_delta.json')
fs.mkdirSync(path.dirname(outPath), { recursive: true })
fs.writeFileSync(outPath, JSON.stringify(delta, null, 2), 'utf8')
console.log(`delta: ${delta.length} 会话待提炼（new=${delta.filter((d) => d.kind === 'new').length} grown=${delta.filter((d) => d.kind === 'grown').length}）`)
```


## 2. 仅对 delta 扇出提炼（`ultracode` Workflow）

把 `_delta.json` 经 Workflow 的 `args` 传入（脚本里 `JSON.parse`），**每个 delta 会话派一个 Sonnet agent**。区分两种：

- **`kind === 'new'`**：照 [`06_insights.md`](../../replication/docs/spec/06_insights.md) §2 全量提炼，agent 直接 **Write** `data/insights/conv/<safe(convId)>.json`（完整对象：`convId/name/isGroup/summary/topics/keyPeople/nuggets[]`）。
- **`kind === 'grown'`**：agent 读 `work/chat-digest-delta/<safe>.txt`（**只有新尾巴**）+（可选）读现有 `data/insights/conv/<safe>.json` 作为语境，**只产出新 nugget**，Write 到 `work/insights-delta/<safe(convId)>.json`：
  ```jsonc
  { "summary": "（可选）据新内容更新后的会话级总结，没有变化可省略",
    "topics": ["（可选）补充的新主题"],
    "keyPeople": ["（可选）新出现的关键人物"],
    "newNuggets": [ { "category":"…", "title":"…", "content":"…(≤140字, 引用用「」)", "people":[], "date":"YYYY-MM", "importance":1 } ] }
  ```

纪律（**MUST**，否则爆窗 / 产废数据，见 [`06_insights.md`](../../replication/docs/spec/06_insights.md) §4）：清单经 `args` 传、agent 只回一行状态、内容落盘、nugget 用 13 类枚举、引用一律中文「」。

> 为什么 grown 不让 agent 直接改 `conv/*.json`？因为"合并 + 去重"是确定性工作，交给脚本做（下一节）比让 LLM 原地改 JSON 更稳、更不会误删旧 nugget。

跑完照例修非法 JSON：
```powershell
python -X utf8 -c "import glob,json,json_repair;[open(f,'w',encoding='utf-8').write(json.dumps(json_repair.loads(open(f,encoding='utf-8').read()),ensure_ascii=False,indent=2)) for f in glob.glob('data/insights/conv/*.json')+glob.glob('work/insights-delta/*.json')]"
```

## 3. 合并 grown 的新 nugget 进已有会话文件（确定性）

存为 `scripts/mergeInsightDelta.ts` 并运行：把每个 `work/insights-delta/<safe>.json` 的 `newNuggets` **追加**进对应 `data/insights/conv/<safe>.json`，按 `title|content` 去重，旧 nugget 一条不动；`summary/topics/keyPeople` 有提供才刷新。

```ts
// scripts/mergeInsightDelta.ts
import fs from 'node:fs'
import path from 'node:path'

const root = process.cwd()
const insDir = path.join(root, 'data', 'insights')
const convDir = path.join(insDir, 'conv')
const deltaDir = path.join(root, 'work', 'insights-delta')
const safe = (id: string) => id.replace(/[<>:"/\\|?*@ -]/g, '_').slice(0, 90)
const key = (n: any) => `${(n.title || '').trim()}|${(n.content || '').trim()}`

const delta = JSON.parse(fs.readFileSync(path.join(deltaDir, '_delta.json'), 'utf8')) as Array<{ convId: string; kind: string }>
let merged = 0, added = 0
for (const d of delta) {
  if (d.kind !== 'grown') continue // 'new' 已由 agent 直接写入 conv/，无需合并
  const sfx = `${safe(d.convId)}.json`
  const dPath = path.join(deltaDir, sfx)
  const cPath = path.join(convDir, sfx)
  if (!fs.existsSync(dPath)) continue
  const patch = JSON.parse(fs.readFileSync(dPath, 'utf8'))
  const conv = fs.existsSync(cPath)
    ? JSON.parse(fs.readFileSync(cPath, 'utf8'))
    : { convId: d.convId, summary: '', topics: [], keyPeople: [], nuggets: [] }

  const seen = new Set((conv.nuggets || []).map(key))
  for (const n of patch.newNuggets || []) { if (!seen.has(key(n))) { conv.nuggets.push(n); seen.add(key(n)); added++ } }
  if (patch.summary) conv.summary = patch.summary
  if (patch.topics?.length) conv.topics = Array.from(new Set([...(conv.topics || []), ...patch.topics]))
  if (patch.keyPeople?.length) conv.keyPeople = Array.from(new Set([...(conv.keyPeople || []), ...patch.keyPeople]))

  fs.writeFileSync(cPath, JSON.stringify(conv, null, 2), 'utf8')
  merged++
}
console.log(`合并 ${merged} 个长大会话，新增 nugget ${added} 条（旧 nugget 未改动）`)
```

```powershell
npx tsx scripts/mergeInsightDelta.ts
```

## 4. 推进高水位 `_state.json`（单调前进）

存为 `scripts/updateInsightState.ts`：对**本轮 delta 的每个会话**，把高水位设为最新 textCount 与最新一条消息时间。

```ts
// scripts/updateInsightState.ts
import fs from 'node:fs'
import path from 'node:path'
import { DatabaseSync } from 'node:sqlite'

const root = process.cwd()
const insDir = path.join(root, 'data', 'insights')
const delta = JSON.parse(fs.readFileSync(path.join(root, 'work', 'insights-delta', '_delta.json'), 'utf8')) as
  Array<{ convId: string; newTextCount: number }>
const state = fs.existsSync(path.join(insDir, '_state.json'))
  ? JSON.parse(fs.readFileSync(path.join(insDir, '_state.json'), 'utf8')) as any[]
  : []
const byId = new Map(state.map((s) => [s.convId, s]))

const db = new DatabaseSync(path.join(root, 'data', 'wechat.db'), { readOnly: true })
const lastStmt = db.prepare('SELECT last_time FROM conversations WHERE id=?')
const stamp = new Date().toISOString() // 记录用；高水位的真实依据是 textCount / last_time
for (const d of delta) {
  const row = lastStmt.get(d.convId) as { last_time?: number } | undefined
  byId.set(d.convId, { convId: d.convId, analyzedTextCount: d.newTextCount, analyzedLastTime: Number(row?.last_time ?? 0), analyzedAt: stamp })
}
db.close()
fs.writeFileSync(path.join(insDir, '_state.json'), JSON.stringify([...byId.values()], null, 2), 'utf8')
console.log(`高水位推进：${delta.length} 个会话已更新到最新`)
```

```powershell
npx tsx scripts/updateInsightState.ts
```
