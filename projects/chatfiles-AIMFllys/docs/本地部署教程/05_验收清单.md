> 把克隆的空壳灌满你自己的数据、并跑起来后，逐项核对。全绿即"部署成功"。

## 阶段验收

- [ ] **环境**（[`01`](01_环境与克隆.md)）：`node -e ...` → `v24+ function`；Python `3.14.x zstd-ok sqlite-ok`；`ffmpeg`/`ffprobe` 有版本；微信（QQ）在跑；`.env.local` 已建（**未提交**）。
- [ ] **定位**（[`02`](02_定位本机数据.md)）：找到 `{{微信数据根}}\{{wxid}}\db_storage\message\message_0.db`（数百 MB、头字节高熵=已加密）；记下无 `--type=` 的主进程 PID；如有 QQ，定位到 `Tencent Files\<QQ号>\nt_qq`。
- [ ] **解密**（[`03`](03_解密解析归档.md) §1）：每库 `pages ok=N bad=0`；Python 能读 `contact.db` 真实联系人（中文可读）。
- [ ] **解析**（[`03`](03_解密解析归档.md) §2）：`data/wechat.db` 有真实会话 / 消息，抽查中文正常。
- [ ] **归档**（[`03`](03_解密解析归档.md) §3）：`data/library.json` `stats.archived > 0`，按一级分类有真实文件；原始源文件一字未改。
- [ ] **提炼**（[`04`](04_提炼与启动.md) §1–3）：`data/insights/conv/*.json` 全部合法；nugget 总数 > 0；`data/insights/boards/*.md` 已生成。
- [ ] **身份**（[`04`](04_提炼与启动.md) §4）：`.env.local` 已填（或刻意留空）；真实身份**未进任何被追踪文件**。
- [ ] **启动**（[`04`](04_提炼与启动.md) §5）：`npm run build` exit 0；`npm start` 打印 `:3456`；`/api/overview`、`/api/insights` 真实数、`/` 200；浏览器各板块可用。

## 安全红线复核（MUST 全部成立）

- [ ] 原始聊天记录 / 文件**一字未改**——解密只写 `work/decrypted/`，归档只复制。
- [ ] 只处理了**你自己的、你拥有的**本机数据。
- [ ] **未上传**任何聊天正文 / 密钥 / 原始库；AI 接入（若用）的密钥不落盘。
- [ ] 解不了的边界（QQ 正文、未登录账号、`.dat` 影像）**如实记录**，未伪造。

## 隐私自检（开源 / 分享前 MUST 跑）

确认没有把个人数据混进会被 git 追踪的地方：

```powershell
# 1) 个人数据目录必须未被追踪（应无输出）
git ls-files data/ archive/ work/ imports/

# 2) 被追踪文件里不应出现你的身份标识（把下面替换成你自己的值后应无命中）
git grep -n -E "你的wxid片段|你的QQ号|你的真实昵称" -- .

# 3) .env.local 必须未被追踪（应无输出）
git ls-files .env.local
```

- [ ] 上述三条均**无输出 / 无命中**——身份只在 `.env.local`，数据只在 gitignored 目录。
