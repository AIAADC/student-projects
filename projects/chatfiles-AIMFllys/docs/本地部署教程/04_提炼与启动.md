# 04 · 提炼与启动

> 本文把灌好的数据**提炼成洞察**，配置好你的身份，最后**把站点跑起来**。
>
> 洞察提炼的完整规格（digest 抽样、nugget schema、聚合、综述、所有陷阱）见 [`06_insights.md`](../../replication/docs/spec/06_insights.md)；本文是部署编排。

---

## 1. 生成 digest + manifest（确定性，纯本地）

```powershell
cd "{{项目目录}}"
npx tsx scripts/prepChatDigests.ts
```

[`scripts/prepChatDigests.ts`](../../scripts/prepChatDigests.ts) 选出**实质会话**（文本消息 `text_count >= 20`），为每个会话生成一份 ≤48000 字、超大群按信息量抽样的 digest 到 `work/chat-digest/`，并写清单 `data/insights/_manifest.json`（每条含 `convId / name / textCount / digest 路径 / first / last`）。

> 这份 `_manifest.json` 是后续提炼的输入，也是 [增量更新](../ChatFiles本地更新/) 计算"哪些会话有新内容"的**基线**——别手动删它。

---

## 2. 多 agent 扇出提炼 nuggets（`ultracode` Workflow）

对 manifest 里**每个会话各派一个 Sonnet agent**：读自己那份 digest → 提炼有长期价值的 nugget → 用 Write 写 `data/insights/conv/<safe(convId)>.json` → **只回传一行状态**（内容落盘，绝不把 nugget 回传主上下文，否则爆窗）。

编排要点（**MUST**，照 [`06_insights.md`](../../replication/docs/spec/06_insights.md) §2/§4）：
- 会话清单经 Workflow `args` 传入（脚本里 `JSON.parse(args)`），**禁止**让单个 bootstrap agent 用 schema 一次性返回几百条。
- 每会话产出 JSON 字段严格遵守 schema：会话级 `convId/name/isGroup/summary/topics/keyPeople/nuggets[]`；nugget `category（13 枚举之一）/title/content(≤140字)/people/date/importance(1-5)`。
- 引用原话一律用中文「」，**禁止** ASCII 直引号（否则 JSON 非法）。

跑完后修复 LLM 偶发的非法 JSON：
```powershell
pip install json-repair
python -X utf8 -c "import glob,json,json_repair;[open(f,'w',encoding='utf-8').write(json.dumps(json_repair.loads(open(f,encoding='utf-8').read()),ensure_ascii=False,indent=2)) for f in glob.glob('data/insights/conv/*.json')]"
```

---

## 3. 按类聚合 → 综述成主题板（`ultracode` Workflow）

遍历 `data/insights/conv/*.json`，把 nugget 按 `category` 归桶到 `work/insights-cat/<类>.json`；再**每类各派一个 Opus agent**写 `data/insights/boards/<类>.md`（导语 + `##/###` 主题 + `>` 原话引用 + 来源）。类名含 `/` 要先净化。详见 [`06_insights.md`](../../replication/docs/spec/06_insights.md) §3。

**✅ 提炼验收**
```powershell
python -X utf8 -c "import glob,json;[json.load(open(f,encoding='utf-8')) for f in glob.glob('data/insights/conv/*.json')];print('all-conv-json-valid')"
python -X utf8 -c "import glob,json;print('nuggets=',sum(len(json.load(open(f,encoding='utf-8')).get('nuggets',[])) for f in glob.glob('data/insights/conv/*.json')))"
(Get-ChildItem 'data/insights/boards/*.md').Count
```
- [ ] `data/insights/conv/*.json` 全部合法 JSON
- [ ] nugget 总数 > 0、主题板 `boards/*.md` 已生成

---

## 4. 配置身份（`.env.local`）

把 [`01`](01_环境与克隆.md) §4 里你的身份补全（构建会把 `VITE_*` 注入前端）：

```ini
VITE_OWNER_WXID=...      # 你 wxid 的子串 → 聊天里"我"的气泡靠右
VITE_OWNER_NAME=...      # 显示成 "我 · <name>"
VITE_OWNER_IDENTITY=...  # 学业板 / 导航上的身份标签（如 "XX大学 XX专业 XX级"）
OWNER_IDENTITY=...       # 同上，给脚本用
VITE_COURSE_URL=...      # 可选：课程站点；留空则隐藏课程卡片
COURSE_URL=...
```

> 这些**只在 `.env.local`**，绝不提交。留空就退化为中性显示，站点照样能跑。

---

## 5. build & run

```powershell
cd "{{项目目录}}"
npm run build      # tsc -b && vite build，必须 exit 0
npm start          # tsx server/index.ts → 打印 ChatFiles running at http://127.0.0.1:3456
```

另开一个 PowerShell 端到端核验（保持上面的 `npm start` 在跑）：
```powershell
(Invoke-WebRequest 'http://127.0.0.1:3456/api/overview'  -UseBasicParsing).Content   # 真实会话/消息/文件/洞察数
(Invoke-WebRequest 'http://127.0.0.1:3456/api/insights'  -UseBasicParsing).Content   # convCount / nuggetCount / boards
(Invoke-WebRequest 'http://127.0.0.1:3456/' -UseBasicParsing).StatusCode             # 200
```

浏览器打开 **http://127.0.0.1:3456**，逐板块点检：聊天能选会话看真实气泡（"我"靠右）；文件树渲染多格式；洞察有碎金卡 + 主题板；学业板显示你的身份标签。

**✅ 启动验收**
- [ ] `npm run build` 退出码 0
- [ ] `npm start` 打印 `:3456` 横幅；`/api/overview`、`/api/insights` 返回真实数；`/` 返回 200
- [ ] 浏览器各板块可用

> 服务端**每请求实时读盘**，所以以后重跑 / 修复数据后**无需重启**即可在站上看到（这是增量更新的运维便利）。
