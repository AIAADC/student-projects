# 01 · 环境与克隆

> 本文把"从拿到仓库到能跑脚本"之间的环境准备一次讲透：克隆、装依赖、配 `.env.local`、自检工具链。命令以 **Windows + PowerShell** 为主。
>
> 这一步**不碰任何原始聊天数据**，纯粹是把跑道铺好。

---

## 1. 克隆仓库（若尚未 clone）

```powershell
git clone https://github.com/AIMFllys/ChatFiles.git
cd ChatFiles
```

> 后文用 `{{项目目录}}` 指代这个仓库根（如 `D:\ChatFiles`）。

clone 下来的就是**空壳**：有 `src/ server/ scripts/ replication/ docs/`，但 `data/ archive/ work/ imports/` 不存在或为空——它们正是要被你的数据灌满的目录，且永远被 `.gitignore` 排除、不会进仓库。

---

## 2. 安装依赖

```powershell
cd "{{项目目录}}"
npm install                          # 安装 package.json 里的全部依赖
npx playwright install chromium      # 无头核验 / 课程站点抓取用（可选但推荐）
```

> 本项目依赖已写死在 `package.json`，`npm install` 一把装齐，**不需要**像从零复刻那样手动 `npm i` 逐个包。

---

## 3. 工具链自检（MUST 全绿再往下）

```powershell
# 1) Node ≥ 24 且 zstd 内建（必须 "function" 而非 "undefined"）
node -e "console.log(process.version, typeof require('node:zlib').zstdDecompressSync)"
#   期望：v24.x.x function

# 2) Python 3.14 + zstd + sqlite3
python -c "import sys,compression.zstd,sqlite3;print(sys.version.split()[0],'zstd-ok','sqlite-ok')"
#   期望：3.14.x zstd-ok sqlite-ok

# 3) ffmpeg / ffprobe 可用
ffmpeg -version | Select-Object -First 1 ; ffprobe -version | Select-Object -First 1

# 4) 微信（QQ）正在运行（解密硬前提）
Get-Process Weixin,QQ -ErrorAction SilentlyContinue | Select Name,Id
```

- [ ] `node -e ...` 打印 `v24+ function`
- [ ] Python 打印 `3.14.x zstd-ok sqlite-ok`
- [ ] `ffmpeg` / `ffprobe` 有版本号
- [ ] `Weixin`（和/或 `QQ`）进程存在

> 任何一项不过，先补齐再继续。详细排障见 [`../../replication/docs/RUNBOOK.md`](../../replication/docs/RUNBOOK.md) Phase 0。

---

## 4. 配置 `.env.local`（你的身份，绝不入仓）

仓库提供模板 `.env.example`。**复制**为 `.env.local`（已被 `.gitignore` 排除），填你自己的值：

```powershell
Copy-Item .env.example .env.local
```

`.env.local` 字段（全部可留空，留空则退化为中性显示）：

```ini
# 聊天板块里"我"的气泡靠右识别
VITE_OWNER_WXID=        # 你自己 wxid 的一个子串（账号目录名里的片段）
VITE_OWNER_NAME=        # 你的显示名，会显示成 "我 · <name>"

# 学业板 / 导航上的身份标签（如 "XX大学 XX专业 XX级"）；留空则显示中性文案
VITE_OWNER_IDENTITY=
OWNER_IDENTITY=

# 可选：要接入的课程 / 成绩站点；留空则隐藏课程卡片、跳过抓取
VITE_COURSE_URL=
COURSE_URL=

# 数据管线覆盖（仅重跑脚本时需要）
WECHAT_STORE=           # 若微信存储被迁出 C:\，填它的绝对路径（见 02 定位）
QQ_NUMBER=              # 你的 QQ 号（Tencent Files 下那个数字目录名）
```

> **MUST NOT** 把真实身份写进任何被 git 追踪的文件；它们只属于 `.env.local`。`VITE_*` 前缀的变量构建时注入前端，其余给 Node 脚本用。字段语义见 `.env.example` 注释与 [`src/boards/ChatMessageList.tsx`](../../src/boards/ChatMessageList.tsx)（`OWNER_WXID/NAME` 消费处）。

`WECHAT_STORE` / `QQ_NUMBER` 现在可以先不填——下一步 [`02_定位本机数据.md`](02_定位本机数据.md) 让 AI 把它们的真实路径找出来后，再回填这里。
