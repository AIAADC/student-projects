# 00 · 总览与前置

> 本文回答：**部署完成后你会得到什么、需要哪些前置条件、本教程与从零复刻的边界、什么算"部署成功"。** 读完它，再按 [`01`](01_环境与克隆.md)→[`05`](05_验收清单.md) 顺序执行。

## 1. 你将得到什么

把这个 clone 下来的空壳灌满你自己的数据后，本机 `http://127.0.0.1:3456` 会跑起一个深色编辑风（「午夜书斋」）的私人档案馆，含 13 个板块：

- **成果组**：概览 · 聊天 · 文件 · 洞察 · 学业 · 媒体
- **配置组**：总结 · 线索 · 聊天整理 · 数据库 · 候选 · 知识 · AI

核心能力：解密并逐条重读**全部**微信会话、VS Code 风格文件树 + 全格式内部预览、多 agent 提炼的洞察碎金 + 主题综述板、可自带模型的 AI 解析浮窗。板块定义详见 [`../../replication/docs/spec/00_overview.md`](../../replication/docs/spec/00_overview.md) 与 [`08_frontend.md`](../../replication/docs/spec/08_frontend.md)。

## 2. 部署 vs 从零复刻（务必先分清）

- 你现在是**部署**：仓库已 clone，`src/`、`server/`、`scripts/` 全在。AI **不需要重写代码**，只需要：定位数据 → 解密 → 跑现成脚本 → 多 agent 提炼 → 配置身份 → `npm run build && npm start`。
- 如果你手上是个**空目录**、想让 AI **从零把代码也造出来**，那不是本教程，请改用仓库根的 [`../../replication/`](../../replication/)（`PROMPT.md` + 12 篇 spec）。

本教程在「解密 / 解析 / 归档 / 提炼」这些**与复刻共享的深技术细节**处，一律**链接**到 `replication/docs/spec/`，不重复抄写——那 12 篇才是唯一权威施工图纸。本教程负责的是**部署编排**：在已有代码上，按正确顺序、用你自己的原料把站点点亮。

## 3. 前置要求（MUST）

| 项 | 要求 | 为什么 |
|---|---|---|
| **Node** | ≥ 24 | 自带 `zlib.zstdDecompressSync`，解析微信 zstd 压缩消息体必需 |
| **Python** | 3.14 | 自带 `compression.zstd` + `sqlite3`，交叉核验解密结果 |
| **ffmpeg / ffprobe** | 在 PATH | 语音转码 + 媒体缩略图 / 视频 poster；缺了媒体网格回退图标、语音不可播 |
| **git** + 联网 | 有 | 拉 Go module / mingw / npm 包 |
| **微信（QQ）** | **正在运行且已登录** | **硬前提**：解密密钥从运行进程内存里取。关掉应用 = 内存里没有 derived encKey = 无法解密 |
| **操作系统** | Windows（本项目环境） | 命令以 PowerShell 为主；进程内存取密钥的实现针对 Windows 微信 4.x |

> 完整的环境自检命令与断言见 [`01_环境与克隆.md`](01_环境与克隆.md) §3 与 [`../../replication/docs/RUNBOOK.md`](../../replication/docs/RUNBOOK.md) Phase 0。

## 4. 成功标准（部署的 Definition of Done，细化见 [`05`](05_验收清单.md)）

- [ ] `.env.local` 已按 [`01`](01_环境与克隆.md) 填好你的身份（**绝不入仓**）。
- [ ] `data/wechat.db` 生成，含真实会话 / 消息（中文正常，非乱码）。
- [ ] `data/library.json` 的 `stats.archived > 0`，按一级分类有真实文件。
- [ ] `data/insights/conv/*.json` 全部合法 JSON，主题板 `data/insights/boards/*.md` 已生成。
- [ ] `npm run build` 退出码 0；`npm start` 打印 `http://127.0.0.1:3456`。
- [ ] 浏览器逐板块可用：聊天看到真实气泡、文件树渲染多格式、洞察有碎金 + 主题板。
- [ ] **全程守住安全红线**：原始文件一字未改、只动副本、不上传、边界如实记录。

## 5. 给执行这套文档的 AI 的总纲

1. **按文件号顺序执行**，每完成一阶段做一次 commit（PADC：规划-分析-实现-提交）。
2. 遇到「解密方式」「数据定位有歧义」这类需要机主拍板的，用 `AskUserQuestion` 问；其余**不确定处自主分析最佳方案**后继续。
3. 涉及大规模洞察提炼时，用 `ultracode` 启用多 agent Workflow 扇出（见 [`../../replication/docs/SKILLS.md`](../../replication/docs/SKILLS.md)）。
4. 任何与原始数据有关的操作，先回看本文件夹 [`README.md`](README.md) 的安全红线；**只读原始、只动副本**是不可逾越的第一原则。
