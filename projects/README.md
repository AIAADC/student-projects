## 如何添加项目

请为每个项目建立一个独立文件夹，推荐命名为：

```text
项目名-你的 GitHub 用户名/
```

目录内至少放置一份 `README.md`，写清楚作者、项目简介、运行方式、演示链接和许可证信息。
