# 月薪喵

一个轻巧、活泼的黄白小猫 Codex App 宠物。

## 文件

- `pet.json`：宠物配置
- `spritesheet.webp`：动画精灵表

## 安装

将本目录复制到：

```text
%USERPROFILE%\.codex\pets\yuexinmiao
```

确保目录中同时存在 `pet.json` 和 `spritesheet.webp`，然后重启 Codex App，或切换一次宠物后重新选择“月薪喵”。
