# 呆猫八条

一只灰白配色、黑色粗线条和大号黄环眼睛的可爱贴纸猫 Codex App 宠物。

## 文件

- `pet.json`：宠物配置
- `spritesheet.webp`：动画精灵表

## 安装

将本目录复制到：

```text
%USERPROFILE%\.codex\pets\daimaobatiao
```

确保目录中同时存在 `pet.json` 和 `spritesheet.webp`，然后重启 Codex App，或切换一次宠物后重新选择“呆猫八条”。
